## القاعدة على `reference/`

**لا يُنقل منها كودٌ كما هو.** ما بُني خارج المستودع لم يرَ الخادم — وذاك سببُ «الشاشة تحسب بدل أن تقرأ».
فالملفات هنا تُقرأ لتُستخرج منها **القاعدة والرقم**، ويُعاد بناء المكوّن داخل المستودع على القواعد الخمس.

⚠️ `reference/rikz-ui-decisions.md` سجلُّ قرارات **الواجهة** بترقيم `و-N` — **ليس** `docs/decisions.md` (سجل `ق-N`)، ولا يُخلط به.
