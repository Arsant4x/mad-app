# `docs/ui/` — الواجهة: القواعد أولاً

**الحالة:** مسوّدة — لا شيء هنا معتمدٌ حتى يحكم المالك على كل جولة.

| المجلد | ما فيه | من يكتبه |
|---|---|---|
| `rounds/` | تقرير كل جولة — **وفي رأسه كتلة «لحكمك» وحدها**، ثم التفصيل | وكيل الواجهة |
| `reference/` | ما أُنتج خارج المستودع ونُقل إليه **مرجعاً لا كوداً**: الأنماط الستة · المرجع البصري · فهرس الأسطح ١٥٨ · سجل قرارات الواجهة `و-N` · مراجعتان | صاحب المشروع (نقلاً) |
| `probes/` | **أدواتُ قياسٍ لا حرّاس ولا شيفرةَ منتَج** — لا تعمل في CI: مسبار القواعد الخمس بالشجرة · مسبار الاستدعاءات التي لا يُستهلك رفضُها · مسبار عرض الجدول بعشرة أعمدة. أرقامُ الجولتين ١ و٢ تُعاد بها | وكيل الواجهة |

## القاعدة على `reference/`

**لا يُنقل منها كودٌ كما هو.** ما بُني خارج المستودع لم يرَ الخادم — وذاك سببُ «الشاشة تحسب بدل أن تقرأ».
فالملفات هنا تُقرأ لتُستخرج منها **القاعدة والرقم**، ويُعاد بناء المكوّن داخل المستودع على القواعد الخمس.

⚠️ `reference/rikz-ui-decisions.md` سجلُّ قرارات **الواجهة** بترقيم `و-N` — **ليس** `docs/decisions.md` (سجل `ق-N`)، ولا يُخلط به.
