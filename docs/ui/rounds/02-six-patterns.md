**٢ · سؤال المقاسات — الرقم:** عشرةُ أعمدةٍ كثيفةٍ بأطول محتوىً واقعي (قائمة العقود، الخطُّ الفعليّ محمَّلاً) تحتاج **١٬١٥٤px** عرضَ محتوى. والقشرةُ القائمة تعطي: **1280 → 970px · 768 → 740px · 375 → 347px**. فيظهر منها **٨ عند 1280 · ٥ عند 768 · و٦ حقولٍ على سطرين عند 375** (والباقي إلى اللوحة). **العشرةُ كاملةً لا تظهر تحت 1٬464px** بالقشرة القائمة. **⇒ لا انكسارَ رابع** — انكسارٌ رابع عند 1440 لا يعطي العشرة (1٬130 < 1٬154)، فالأداة **أولويةُ الأعمدة** (يبقى · ينتقل إلى اللوحة) بالأعداد المقيسة لا نقطةُ توقّف. *(وإن أردتَ العشرة عند 1280: القضيبُ الجانبيّ 64px يعطي 1٬156 — بهامش **2px**؛ ولا أنصح بضمانٍ على هامشٍ كهذا.)*

**٣ · مطابقة الجزء الرابع من المراجعة — النتيجة:** **كلُّ أسطر الواجهة فيه قائمةٌ في الشجرة الحالية** (١٩ موضعاً في ① و③ و⑤ طابقت موضعاً موضعاً)، **وسطرٌ واحدٌ لم يُطابَق**: «`InvoiceListView` و`pages/purchases` قوائمُ كاملة ثم `Pager` في الشاشة» — لا `Pager` في الفواتير ولا مجلد `purchases` أصلاً؛ الفواتير **بلا ترقيمٍ إطلاقاً** (وهذا أسوأ لا أهون). وثلاثةُ أرقامٍ صحّحها القياس الأدقّ: **صفحاتُ التحميل بلا معالج ١٨ — كلُّها مؤكَّدة**، **والسطحُ الكامل للقاعدة ② ٢٤٠ موضعاً في ٥٩ ملفاً** (المراجعةُ عدّت التحميل وحده، ومسباري الأول عدّ `useEffect` وحده — والاثنان نصفان)؛ و`.catch(() => {})` **الصامت ١٧ موضعاً** لا ٥. **وخلافٌ واحد في الحكم**: `HrPage.tsx:110` تعدّه المراجعة «سليماً» — وتحت القاعدة ① كما أُقرّت هو مخالفة (جمعُ `r.days` في الشاشة رقمٌ يُقرأ)؛ **أُبقيه مخالفةً إلا أن تحكم بغيره**.

**٤ · نقطتان تخالفان مرجعاً سابقاً — أعلنهما:** (أ) مواصفةُ الأنماط في `reference/six-patterns-spec.md` (ك-٧ · `ق-١٠٨`) تقول «عند 375 الجدول **يمرّر أفقياً** ولا عمود مخفي» — **وقرارُك الأحدث ينسخها**: مصفوفاً بسطرين ولا تمرير؛ فالمرجع يُقرأ على هذا. ## ٢ · ثلاثُ نتائج من القياس تُغيّر تصميمَ الحرّاس

1. **`.catch(() => {})` ليس معالجة.** ١٧ موضعاً تبتلع الخطأ فتُبقي القائمة فارغةً بلا كلمة. حارسُ ② يُسقط `catch` **بجسمٍ فارغ** أو بردّ نداءٍ لا يلمس حالةً (AST: `ArrowFunction` بـ`Block` بلا عبارات، أو تعبيرٌ لا يستدعي دالّة). **والبنيةُ تجعله مستحيلاً**: `useResource` لا يقبل معالجاً — الخطأ **حالةٌ** في الاتحاد لا ردُّ نداء.
2. **معالجٌ في موضعٍ يخفي غيابه في آخر.** مسباري الأول رأى `catch` في دالّة `load` فأعفى الملف كلَّه — و`InvoicesPage` فيها ٤ مواضع بلا معالج من ٩. فالحارس يحكم **على كل استدعاءٍ** لا على الملف.
3. **الفواتير بلا ترقيمٍ لا بترقيمٍ وهمي.** فقائمةُ استثناء ④ تبدأ بـ`listInvoices` **بعددٍ يُطبع في كل تشغيل** (شرطُك).

## ٣ · الأوّليات المشتركة — ما تُبنى عليه الأنماط الستة

```ts
// api/wire.ts — أنواع السلك الموسومة (①/③)
export type Money = string & { readonly __wire: 'Money' };      // "1234.50"
export type Qty   = string & { readonly __wire: 'Qty' };
export type Count = number;                                        // أعدادٌ لا مبالغ — الحسابُ عليها جائز

// api/page.ts (④)
export interface Page<T> { items: T[]; total: Count; page: Count; pageSize: Count }

// hooks/useResource.ts (②) — الحدُّ الوحيد الذي يلمس api/
export type Resource<T> =
  | { status: 'loading' }
  | { status: 'error'; error: ApiError }              // ApiError: { status, code, message, requestId }
  | { status: 'forbidden'; grantedBy: string | null } // 403 — من يمنح، من رسالة الخادم
  | { status: 'empty'; filtered: boolean }            // filtered: بعد بحثٍ أم أول مرة
  | { status: 'partial'; data: T; failed: string[] }  // بعضُ المصادر سقط — مسمّاةً
  | { status: 'ready'; data: T };

// components/ResourceView.tsx — كلُّ الفروع إلزامية؛ حذفُ فرعٍ خطأُ ترجمة
<ResourceView r={r} loading={…} error={…} forbidden={…} empty={…} partial={…} ready={…} />
```

**الحالاتُ الستّ — تعريفٌ واحد يُقرأ في كل نمط:**

| الحالة | ما يراه التاجر | ما لا يراه أبداً |
|---|---|---|
| **تحميل** | هيكلٌ رماديّ بأبعاد المحتوى الحقيقي (٢٥ صفاً × ٣٢px) والعنوانُ حقيقيّ | رقمٌ · صفر · «لا شيء» |
| **فارغٌ أول مرة** | جملةٌ تقول ما سيظهر هنا + **الفعلُ الأول** (إن ملك صلاحيته) | فلترٌ · بحثٌ · شريطُ أدوات |
| **فارغٌ بعد بحث** | «لا نتيجة لـ«…» — من **N** إجمالاً» + «امسح البحث» | «لا فواتير بعد» |
| **خطأ** | «تعذّر جلب …» + سببُ الخادم بلغته + **رقمُ الطلب** + «أعد المحاولة» | هيكلُ الفارغ · أصفار · جدولٌ فارغ |
| **ممنوعٌ بالصلاحية** | «لا تملك صلاحية … — **ومن يمنحها: X**» + «اطلب الصلاحية» | الجدولُ مخفيّاً بلا سبب |
| **ناقصٌ جزئياً** | المحتوى **مع شريطٍ فوقه** يسمّي ما نقص وعددَه، والخلايا الناقصة `—` | جدولٌ يبدو مكتملاً |

**والقاعدةُ التي تحكم الستّ:** الحالةُ **تأتي من `Resource`** لا تُستنتج من `data.length === 0` — فاستنتاجُها هو ما جعل السقوط يبدو فراغاً.

**الكثافة والمقاسات (مقرَّرة):** كثيفٌ أساساً · **لمسٌ دون 768**. القشرةُ القائمة: شريطٌ جانبيّ 250px فوق 860، ومنزلقٌ تحته؛ الحشوة 30 ثم 14.

| المقاس | عرضُ المحتوى | الكثافة | الصفّ | الهدفُ اللمسيّ |
|---|---|---|---|---|
| **1280** | **970px** | كثيف | 32px | — |
| **768** | **740px** | كثيف | 32px | — |
| **375** | **347px** | **لمس** | 48px (سطران × 24) | ≥ 44px |

## ٤ · النمط الأول — الجدول `DataTable<T>`

**ما يقبله (البنية على ④ و② و③):**
```ts
{ r: Resource<Page<T>>; columns: Column<T>[]; onPage(page: Count): void; rowKey(t: T): string;
  onRow?(t: T): void;               // يفتح اللوحة (النمط ٦) — الأعمدةُ المنقولة تُقرأ هناك
  actions?: RowAction<T>[] }        // كلُّ فعلٍ يحمل grant: Grant، ولا يُرسم بلا can(grant)
Column<T> = { key; header; cell(t): ReactNode; kind: 'text'|'id'|'date'|'money'|'qty'|'status';
              minWidth: number;     // مقيسٌ لا مقدَّر — أعرضُ محتوىً واقعي لهذا العمود
              priority: 1|2|3;      // ١ يبقى في كل مقاس · ٢ يبقى فوق 768 · ٣ يبقى حين يتّسع
              stack?: 'line1'|'line2' }  // موضعُه في الصفّ المصفوف عند 375 — وإلا فاللوحة
```
**لا خاصية `rows: T[]`** — مصفوفةٌ كاملة لا تدخل الجدول (خطأ نوع). ولا `reduce` داخله؛ **مجموعُ الأعمدة** مكوّنٌ منفصل `<ColumnSum>` يكتب «مجموعُ المعروض» على الشاشة (شرطُ القبول)، **ويُعطَّل نوعياً على `Page<T>`** فلا يجمع صفحةً ويسمّيها كلاً.

**كيف تُوزَّع الأعمدة — بالقياس لا بالتقدير:** الجدول يقرأ عرضَ حاويته، ويجمع `minWidth` بترتيب الأولوية ثم الترتيب، **ويعرض ما يدخل ويحيل الباقي إلى اللوحة** — ويكتب في رأسه «N من M عموداً · الباقي في التفاصيل». ولا تمريرَ أفقيّاً في أيّ مقاس.

**المقيس على قائمة العقود (عشرة أعمدة، الخطُّ الفعليّ، 13.5px، حشوةُ خلية 12px):**

| رقم العقد | 115 | ١ | line1 |
| المستأجر | 190 | ١ | line2 |
| الوحدة · العقار | 166 | ١ | line2 |
| النهاية | 100 | ١ | line2 |
| الحالة | 91 | ١ | line1 |
| المتبقّي | 97 | ١ | line1 |
| الإيجار السنوي | 108 | ٢ | لوحة |
| التصنيف | 94 | ٢ | لوحة |
| البداية | 100 | ٣ | لوحة |
| التأمين | 97 | ٣ | لوحة |
| **المجموع** | **1٬154** | | |

**السلوك بالمقاسات — أعدادٌ لا أوصاف:**

| الحالة | الرسم | الرقم |
|---|---|---|

## ٥ · النمط الثاني — النموذج (`FormSection` · `Field` · `FormActions`)

**البنية على القواعد:** القيمُ نصوصٌ كما على السلك (`Money` لا `number`) — **لا حسابَ في النموذج**: المعاينةُ (`InvoiceBuilderView:65` · `QuoteModal:41` · `DebitNoteModal:30` · `PosPage:127`) تُطلب من الخادم `POST …/preview` **بالدالّة نفسها** التي تختم (`computeDocumentTotals`) — **وهذا بندٌ خامس للخادم إن لم تكن `preview` قائمة**؛ حتى تقع، المعاينةُ **تُخفى** لا تُحسب. الحفظُ بـ`useMutation` **`onError` إلزاميٌّ في النوع**، وأخطاءُ الحقول من `fieldErrors` في جسم `400` تُلصق بحقلها. الفعلُ الأساسي من `can(grant)`، **والحبرُ لما في `ISSUE_ACTIONS` وحده**.

**الأرقام:** الحقل 36px كثيفاً / **44px** لمساً · التسمية 12.5px فوق الحقل · الإدخال 13.5px · الفجوة 12 · عمودان فوق 768 (أدنى عرض للعمود 300px) وعمودٌ عند 375 · شريطُ الأفعال لاصقٌ أسفل 56px · رسالةُ الخطأ تحت الحقل 12px بلون `bad` **وتبقى حتى يتغيّر الحقل**.

| الحالة | في النموذج |
|---|---|
| تحميل (سجلٌّ قائم) | **هياكلُ الحقول** بأبعادها — لا حقولٌ فارغة تُوهم بأنها للإدخال |
| فارغٌ أول مرة (سجلٌّ جديد) | الحقولُ فارغة، **بلا صفرٍ افتراضيّ في مبلغ** — الافتراضيُّ من `defaults` الخادم أو لا شيء |
| فارغٌ بعد بحث (قائمةُ اختيار) | «لا خيار يطابق «…»» + «امسح» داخل القائمة المنسدلة |
| خطأ (حفظ) | شريطٌ أعلى النموذج بالسبب و`requestId` + أخطاءُ الحقول في مواضعها · **القيمُ محفوظة** |
| ممنوع | **الحقولُ مرئيةٌ مقفلة** + سطرٌ يقول من يمنح — لا نموذجٌ مخفيّ |
| ناقص | قسمٌ مصدرُه سقط (قائمةُ عملاء) يعرض «أعد المحاولة» في مكانه · الحفظُ معطَّل **بسببٍ مكتوب** |

**عند 375:** عمودٌ واحد · الخطواتُ (`WizardSteps`) شريطُ تقدّمٍ 4px بدل الأرقام · شريطُ الأفعال لاصقٌ بزرَّين 44px.

**القبول:** `useMutation` بلا `onError` خطأُ نوع · `400` بـ`fieldErrors: { vatNumber: '…' }` ⇒ الرسالةُ تحت الحقل نفسه · حقلُ مبلغٍ جديد **فارغٌ** لا `0.00`.

## ٦ · النمط الثالث — البطاقة `SummaryCards`

**البنية:** `r: Resource<Card[]>` · `Card = { key; label; value: Money | Count | null; filterKey?: string }`. **الرقمُ من الخادم** — لا مجموعَ في البطاقة (اللوحة `DashboardPage:46-50` هي عطبُ ①). **النقرُ يفلتر** (قاعدةٌ عامة بقرارك) **بشرط أن يُرى**: البطاقةُ المضغوطة تحمل حدّاً 2px بلون العلامة وعلامة `aria-pressed`، **والجدولُ يكتب في رأسه «N من M»** — **ولا شريطَ فلترة** (⛔ الفلترة لا تُعرض). النقرُ الثاني يفكّ.

**الأرقام:** البطاقة 88px كثيفاً · الرقم **28px بـIBM Plex** (لا Readex — و-١٧: Readex بلا أرقامٍ جدولية) · التسمية 12.5px · الشبكة: **٤** أعمدة عند 1280 (٤ × 220 + ٣ × 12 = 916 ≤ 970) · **٢** عند 768 · **٢** عند 375 (2 × 165 + 12 = 342 ≤ 347).

| الحالة | في البطاقة |
|---|---|
| تحميل | هيكلٌ مكان الرقم 28px |
| فارغٌ أول مرة | **`—`** والتسمية · لا `0` |
| فارغٌ بعد بحث | لا ينطبق — البطاقاتُ مجاميعُ النطاق كله من الخادم؛ حين تُضغط بطاقةٌ تبقى الأخريات كما هي |
| خطأ | «تعذّر» + «أعد» داخل البطاقة · لا رقم |
| ممنوع | البطاقةُ ظاهرة **بقفلٍ ومن يمنح** — لا مخفيّة |
| ناقص | البطاقةُ التي سقط مصدرُها في حالة خطأ، وسائرُها سليم |

**القبول:** `value: number` من حسابٍ محليّ خطأُ نوع (`Money` أو `Count` من `api/` فقط) · البطاقةُ المضغوطة تغيّر رأسَ الجدول إلى «N من M» في نفس الدورة.

## ٧ · النمط الرابع — شارة الحالة `StatusBadge`

**البنية:** `badgeFor(map, status)` — الخريطةُ من تعداد Prisma عبر الحارس القائم (`statusBadge.ts`)، **والقيمةُ غيرُ المعروفة تُرسم شارةً محايدةً بنصّ الرمز الخام** ولا تُخفى (بندُ 4.5 الدَّين المسجَّل: `PARTIAL` أُضيف للخادم ولم يصل الواجهة — الشارةُ المحايدة تجعل هذا **مرئياً** لا منهاراً).

**الأرقام:** الارتفاع 20px · الحشوة 2×8 · 12px/500 · نصفُ قطرٍ 999 · النغمات `ok · warn · bad · info · muted` من الرموز وحدها.

| الحالة | الشارة |
|---|---|
| تحميل | هيكلٌ 60×20 |
| فارغٌ أول مرة | `—` (لا حالة بعد) |
| فارغٌ بعد بحث | لا ينطبق (ذرّية) |
| خطأ | شارةٌ `muted` بنصّ «تعذّر» |
| ممنوع | لا تُرسم؛ الخليةُ `—` بقفلٍ وتلميحٍ يقول من يمنح |
| ناقص | حين يرسل الخادم `stale: true` — الشارةُ بنغمتها **مع علامةٍ صغيرة وتلميح «غير محدَّث منذ …»** |

**القبول:** تعدادٌ يُضاف في Prisma بلا مقابلٍ في الخريطة ⇒ الحارسُ القائم يسقط، **والشارةُ وقتَ التشغيل ترسم الرمز الخام لا فراغاً**.

## ٨ · النمط الخامس — رأسُ الصفحة `PageHeader` + `WarningBar`

**البنية:** العنوان (Readex 20px — يجوز فيه رقمُ معرّف لا مبلغ) · العنوان الفرعي · **فعلٌ أساسيّ واحد** من `can(grant)` (حبرٌ إن كان في `ISSUE_ACTIONS`، وإلا العلامة) · فعلٌ ثانوي · قائمةُ ⋯ · تبويبات · **سطرُ العدّ** «N من M» يقرأ `Page.total`. `WarningBar` تحت الرأس مباشرة: نغمةٌ ونصٌّ وفعل.

**الأرقام:** الرأس 56px كثيفاً · لاصقٌ أعلى · التبويبات 40px · `WarningBar` 36px · عند 375: العنوان 18px، **فعلٌ واحدٌ ظاهر + ⋯** (الباقي في القائمة)، الأفعالُ 44px.

| الحالة | في الرأس |
|---|---|
| تحميل | العنوانُ من المسار فوراً · العدُّ هيكل · الأفعالُ ظاهرة **معطَّلة** |
| فارغٌ أول مرة | الفعلُ الأساسي بارز · لا عدّ |
| فارغٌ بعد بحث | «٠ من M» |
| خطأ | الرأسُ كما هو + `WarningBar` بالسبب و«أعد» · الأفعالُ الكتابية معطَّلة |
| ممنوع | العنوان + جسمُ `AccessDenied` يسمّي من يمنح · **لا أفعال** |
| ناقص | `WarningBar`: «تعذّر جلب X لـN — المعروضُ صحيح وعمودُ X ناقص» |

**القبول:** فعلٌ بلا `grant` خطأُ نوع · `ISSUE_ACTIONS` هي مصدرُ الحبر (و-٤) · العدُّ يطابق `total` لا `items.length`.

## ٩ · النمط السادس — الحوار (`SidePanel` · `ConfirmDialog`)

**البنية:** اللوحةُ تفتح على صفّ، تعرض **الأعمدةَ المنقولة أولاً** (ما لم يدخل الجدول) ثم التبويبات؛ محتواها `Resource<T>` لكل تبويب. `ConfirmDialog` يسمّي **الأثر** («سيُلغى العقد ويُردّ التأمين 5٬000.00») لا «هل أنت متأكد» — والمبلغُ من الخادم (`preview`) لا من الشاشة. الفعلُ الخطر بنغمة `bad` ويحمل `grant`.

**الأرقام:** اللوحة **440px** عند 1280 (يبقى للجدول 530 — فتُعاد قسمةُ الأعمدة عليه: **٤** حتى «النهاية» 571 ✗ → **٣** أعمدة 471 ✓ والباقي في اللوحة نفسها) · عند 768 **تغطي كامل العرض** فوق الجدول · عند 375 **ورقةٌ كاملة** بزرّ رجوع 44px · رأسُ اللوحة 56 · التبويبات 40 · التذييل لاصق 56 · `ConfirmDialog` أقصى 440، زرّان، مصيدةُ تركيز، `Esc` يغلق إلا أثناء طلبٍ جارٍ.

| الحالة | في اللوحة |
|---|---|
| تحميل | الرأسُ حقيقي (من الصفّ) · الجسمُ هيكل |
| فارغٌ أول مرة | تبويبُ «المرفقات»: «لا مرفقات بعد» + «أضف» إن ملك الصلاحية |
| فارغٌ بعد بحث | داخل تبويبٍ يُرشَّح: «لا نتيجة» + «امسح» |
| خطأ | الرأسُ باقٍ · الجسمُ خطأ + «أعد» · التبويباتُ الأخرى تعمل |
| ممنوع | التبويبُ **ظاهر** · جسمُه يقول من يمنح |
| ناقص | تبويبٌ واحدٌ في خطأ، وشارةٌ على اسمه |

**القبول:** فتحُ اللوحة عند 1280 يُعيد توزيعَ الأعمدة إلى ٣ بلا تمريرٍ أفقيّ (مقيسٌ بـ`scrollWidth`) · `ConfirmDialog` بلا نصّ أثرٍ خطأُ نوع (`effect: string` إلزامي).
